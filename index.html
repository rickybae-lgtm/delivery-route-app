계산 방식

2오늘의 방문 순서

화살표(↑↓)나 "맨뒤로"로 옮긴 곳들은 그 위치에 그대로 고정되고(여러 곳을 옮기면 옮긴 곳 전부 고정), 나머지 배달처들은 고정된 지점들 사이사이에서 실제 도로거리 기준으로 자동 재배치돼요. 처음부터 완전히 새로 최적화하고 싶으면 "전체 다시 최적화"를 눌러주세요(고정도 다 풀립니다).

3업체등록 / 수정

이름과 주소만 입력하고 저장하면 자동으로 좌표를 찾아 저장합니다. 자동으로 못 찾으면 알려드리니 그때만 수동으로 넣으시면 됩니다.
지금 서 계신 곳을 등록할 때 주소를 몰라도 이 버튼으로 좌표와 주소를 자동으로 채울 수 있어요. (스마트폰 위치 권한 허용 필요)
좌표 직접 입력 / 확인 (평소엔 안 열어보셔도 됩니다)

4업체 목록

기기를 바꾸거나 다른 사람 것과 합칠 때, 이 기기의 업체 목록을 파일로 내려받은 뒤 새 기기에서 "불러오기"로 열면 옮길 수 있어요.
